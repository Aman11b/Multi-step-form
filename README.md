# Frontend Mentor - Multi-step Form

![Design preview for the Multi-step Form coding challenge](./preview.jpg)

A responsive multi-step subscription form built with **Next.js, React, TypeScript, and Tailwind CSS** as part of a Frontend Mentor challenge.

## 📖 Overview

The application guides users through a multi-step subscription process, allowing them to enter personal information, choose a subscription plan, select add-ons, and review their order before confirming.

## ✨ Features

- **Multi-step navigation** – Move between form steps using Next and Go Back controls.
- **Form validation** – Validate required fields and input formats.
- **Plan selection** – Choose between Arcade, Advanced, and Pro plans.
- **Billing options** – Switch between monthly and yearly billing.
- **Add-on selection** – Select optional subscription add-ons.
- **Order summary** – Review the selected plan, add-ons, and total price.
- **State persistence** – Preserve selections when navigating between steps.
- **Responsive design** – Adapt the layout for mobile and desktop screens.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Aman11b/Multi-step-form.git
cd Multi-step-form
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🧪 Running Tests

Run the Playwright end-to-end tests:

```bash
npx playwright test
```

View the HTML test report:

```bash
npx playwright show-report
```
